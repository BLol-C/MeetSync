# บทพูดประชุมจำลอง + เฉลย

ใช้ซ้อมสายงานกับ Google Meet จริง (ให้ 3 คนอ่านออกเสียง) และใช้เป็นเคสวัดคุณภาพ AI ใน `evaluation/cases/script_meeting_th/`
บทนี้เขียนให้มี "กับดัก" ไว้ทดสอบ: วาระที่ไม่มีมติ (ห้ามให้ AI แต่งมติ), งานไม่มีกำหนดวัน, วันแบบสัมพัทธ์ ("วันพุธหน้า"), ศัพท์อังกฤษปน (deploy, API, database, cloud)

## ก่อนเริ่ม

| ตัวละคร | บทบาทในระบบ | หมายเหตุ |
|---|---|---|
| **ต้น** | ประธาน (chair) | ผู้พูดหลัก พูดมากที่สุด |
| **ฟ้า** | เลขา (secretary) | |
| **บอล** | ผู้เข้าร่วม (attendee) | |
| **แพร** | ผู้เข้าร่วม — **ไม่มา (absent)** | ไม่ต้องเข้า Meet แต่ต้องมีชื่อในรายชื่อ เพื่อทดสอบหัวข้อ "ผู้ไม่มาประชุม" |

1. สร้างการประชุมในแท็บ ① ใส่รายชื่อ 4 คนตามตาราง ตั้งบทบาทและสถานะ (แพร = ไม่มา) **ชื่อต้องตรงกับชื่อที่แสดงใน Meet** ของแต่ละคน
   (ถ้าชื่อใน Meet ต่างออกไป ใช้ "รวม" ในแท็บ ③ ได้ภายหลัง)
2. **วันที่ซ้อม:** เฉลยตั้งไว้สำหรับการประชุมวันที่ **3 ตุลาคม 2569 (วันเสาร์)** ถ้าซ้อมวันอื่น ให้แก้ `date` ใน `case.json` และแก้ `due_date` ของงาน "เตรียมสไลด์"
   ให้เป็นวันพุธถัดไปของวันที่ซ้อม (ข้อความในบทพูดว่า "ภายในวันพุธหน้า") ส่วนวันอื่นในบทเป็นวันที่ตายตัว ไม่ต้องแก้
3. เริ่มบอทแล้วให้ทุกคนพูดตามบทด้านล่าง **พูดธรรมชาติ ไม่ต้องรีบ เว้นจังหวะเล็กน้อยเมื่อเปลี่ยนคน อย่าพูดทับกัน** (CC ของ Meet จับคนพูดทับกันไม่ดี)
4. ต้องเปิด CC ของ Meet ให้เป็นภาษาไทย (บอทเปิดให้เอง)

## บทพูด (ประมาณ 5–7 นาที)

**ต้น:** สวัสดีครับทุกคน วันนี้แพรติดธุระไม่ได้มาประชุมนะครับ วันนี้เรามีสี่เรื่อง เรื่องแรกความคืบหน้าของระบบ เรื่องที่สองงบประมาณค่า API เรื่องที่สามการซ้อมนำเสนอ และเรื่องสุดท้ายการย้าย database ขึ้น cloud
**ต้น:** เริ่มจากเรื่องแรก บอลช่วยรายงานความคืบหน้าหน่อยครับ
**บอล:** ครับ ตอนนี้ผม deploy ระบบขึ้นเครื่องทดสอบเรียบร้อยแล้ว ใช้งานได้ปกติ ยังเหลือแก้บั๊กเล็กน้อยเรื่องหน้า login
**ต้น:** ครับ รับทราบ เรื่องนี้แจ้งเพื่อทราบนะครับ ยังไม่ต้องตัดสินใจอะไร
**ต้น:** เรื่องที่สอง งบประมาณค่า API ของ Gemini เดือนที่แล้วเราใช้ไปประมาณหนึ่งพันห้าร้อยบาท ผมเสนอให้ตั้งงบเดือนละสามพันบาท
**ฟ้า:** เห็นด้วยค่ะ แต่ขอให้มีใบขอเบิกงบก่อนนะคะ
**บอล:** ผมเห็นด้วยครับ
**ต้น:** ถ้าอย่างนั้นสรุปว่าที่ประชุมอนุมัติงบค่า API เดือนละสามพันบาท และให้ฟ้าจัดทำใบขอเบิกงบ ภายในวันที่ 12 ตุลาคม
**ฟ้า:** รับทราบค่ะ ดิฉันจะทำใบขอเบิกงบให้เสร็จภายในวันที่ 12 ตุลาคม
**ต้น:** เรื่องที่สาม การซ้อมนำเสนอ ผมอยากนัดซ้อมวันที่ 16 ตุลาคม ตอนบ่ายโมง ทุกคนสะดวกไหมครับ
**ฟ้า:** สะดวกค่ะ
**บอล:** ผมก็สะดวกครับ
**ต้น:** ตกลงตามนี้ ซ้อมนำเสนอวันที่ 16 ตุลาคม เวลาบ่ายโมง ผมจะเป็นคนจัดซ้อมเองนะครับ
**ต้น:** แล้วบอลช่วยเตรียมสไลด์นำเสนอให้เสร็จภายในวันพุธหน้านะครับ
**บอล:** ได้ครับ ผมจะเตรียมสไลด์ให้เสร็จภายในวันพุธหน้า
**ต้น:** เรื่องสุดท้าย ผมคิดว่าการย้าย database ขึ้น cloud น่าจะดี แต่ยังไม่รู้ว่าราคาเป็นอย่างไร
**ฟ้า:** ใช่ค่ะ ตอนนี้ยังไม่มีข้อมูลพอ ควรรอดูราคาก่อนค่ะ
**ต้น:** งั้นเรื่องนี้ยังไม่ตัดสินใจนะครับ ขอรอข้อมูลก่อน บอลช่วยหาราคา cloud database มาเปรียบเทียบสักสองสามเจ้า ภายในวันที่ 14 ตุลาคม
**บอล:** รับทราบครับ ภายในวันที่ 14 ตุลาคม
**ต้น:** นอกจากนี้ฟ้าช่วยอัปเดตเอกสารความคืบหน้าในโฟลเดอร์กลางด้วยนะครับ ไม่ต้องรีบ
**ฟ้า:** ได้ค่ะ
**ต้น:** ครับ ไม่มีเรื่องอื่นแล้ว ขอบคุณทุกคนครับ ปิดประชุมครับ

## เฉลย (สิ่งที่รายงานควรได้)

**วาระและมติ**

| # | วาระ | มติที่ถูกต้อง |
|---|---|---|
| 1 | ความคืบหน้าระบบ (deploy ขึ้นเครื่องทดสอบแล้ว) | **ไม่มีมติ** (แจ้งเพื่อทราบ) |
| 2 | งบประมาณค่า API | **อนุมัติ** งบเดือนละ 3,000 บาท |
| 3 | การซ้อมนำเสนอ | **ซ้อมวันที่ 16 ตุลาคม เวลา 13:00** |
| 4 | ย้าย database ขึ้น cloud | **ไม่มีมติ** (ยังไม่ตัดสินใจ รอข้อมูลราคา) ← กับดัก: AI ต้องไม่แต่งว่า "อนุมัติ/เห็นชอบย้าย" |

**งานที่ได้รับมอบหมาย**

| # | งาน | ผู้รับผิดชอบ | กำหนด |
|---|---|---|---|
| 1 | จัดทำใบขอเบิกงบ | ฟ้า | 2026-10-12 |
| 2 | เตรียมสไลด์นำเสนอ | บอล | 2026-10-07 (วันพุธหน้า — ดูหมายเหตุวันที่ซ้อม) |
| 3 | จัดซ้อมนำเสนอ (13:00) | ต้น | 2026-10-16 |
| 4 | หาราคา cloud database มาเปรียบเทียบ | บอล | 2026-10-14 |
| 5 | อัปเดตเอกสารความคืบหน้าในโฟลเดอร์กลาง | ฟ้า | **ไม่มีกำหนด** (ว่าง) ← กับดัก: AI ต้องไม่เดาวัน |

**ส่วนหัวรายงาน (มาจากระบบ ไม่ใช่ AI):** ประธาน = ต้น, เลขา = ฟ้า, ผู้มาประชุม = ต้น ฟ้า บอล, ผู้ไม่มา = แพร

## หลังซ้อมเสร็จ: ใช้เป็นเคสวัดผลจริง
1. ตรวจและแก้ transcript ในแท็บ ③ ให้ตรงกับที่พูดจริง (ถ้า CC ถอดผิด) แล้วรวมชื่อให้ตรงรายชื่อ
2. กด "⬇ ดาวน์โหลด .txt" แล้วนำไฟล์ไปแทน `evaluation/cases/script_meeting_th/transcript.txt`
   (ตัวโหลดเคสตัดเวลานำหน้า `[10:02:15–10:02:40]` ให้เอง)
3. ใน `case.json` เปลี่ยน `"synthetic": true` เป็น `false` (เพราะตอนนี้เป็น transcript ที่ได้จาก Meet จริงแล้ว)
4. รัน `venv\Scripts\python evaluation\run_eval.py --case script_meeting_th --repeat 3`
   เอาตารางผลที่ได้ไปใช้เป็นหลักฐาน (ไฟล์อยู่ใน `evaluation/results/`)

เทียบ 3 ค่าที่ต้องจับตา: **มติที่แต่งขึ้น** (วาระ 1 และ 4 ต้องไม่มีมติ), **ผู้รับผิดชอบ/วันกำหนดถูกต้อง**, และ **งานที่ 5 ต้องไม่มีวันที่**
