# เช็กลิสต์ซ้อมกับ Google Meet จริง

เป้าหมาย: พิสูจน์ว่าสายงานทั้งเส้น (สร้างประชุม → บอทเข้า Meet → จับ CC → ตรวจ transcript → AI ร่างรายงาน → PDF) ใช้ได้กับ Meet จริง
บทพูดและเฉลยอยู่ใน `SCRIPT_MEETING.md` (ใช้ร่วมกับไฟล์นี้) **บันทึกทุกอย่างที่พังหรือผิดปกติ ไม่ว่าเล็กแค่ไหน** — ผลซ้อมคือหลักฐานให้อาจารย์

## 0) เตรียมก่อนวันซ้อม
- [ ] คนอ่านบท 3 คน (ต้น, ฟ้า, บอล) พร้อมหูฟัง/ไมค์ แพรไม่ต้องเข้า Meet
- [ ] `git pull` จาก `main` ให้เป็นเวอร์ชันล่าสุด
- [ ] `.env` มีคีย์ครบ (Gemini ฯลฯ) และมี `.streamlit\secrets.toml` (สร้างอัตโนมัติจาก `.\run` ได้)
- [ ] บัญชี Google ของบอทล็อกอินในโปรไฟล์ `.meet_profile/` แล้ว (ถ้าหมดอายุ ต้องล็อกอินใหม่ก่อนซ้อม ไม่ใช่ระหว่างประชุม)
- [ ] สร้างห้อง Meet ล่วงหน้า และรู้ว่าบอทต้องได้รับอนุญาตเข้าห้อง (ใครเป็นคนกดอนุญาต)
- [ ] ปิดโปรแกรมหนักอื่นๆ เพื่อให้ตัวเลข memory ภายหลังเทียบได้
- [ ] วันที่ซ้อมไม่ใช่ 3 ต.ค. 2569 → แก้ `date` ใน `evaluation/cases/script_meeting_th/case.json` และ `due_date` งาน "เตรียมสไลด์" เป็นวันพุธถัดไป (ดู `SCRIPT_MEETING.md`)

## 1) เริ่มระบบ
- [ ] `.\run` แล้วเปิด http://localhost:8501
- [ ] ล็อกอินผ่าน Streamlit ได้ (redirect URI `http://localhost:8501/oauth2callback`)
- [ ] แท็บ ① สร้างประชุม ใส่ 4 คน: ต้น=ประธาน, ฟ้า=เลขา, บอล=ผู้เข้าร่วม, แพร=ผู้เข้าร่วมสถานะไม่มา
  (ชื่อต้องตรงกับชื่อที่แสดงใน Meet) ใส่วาระ/ลิงก์ Meet
- [ ] **ตรวจ:** บริการบอท (พอร์ต 8000) ขึ้นและหน้าเว็บเห็นสถานะบอทว่า "พร้อม"

## 2) บอทเข้าห้อง
- [ ] กดเริ่มบอทจากหน้าเว็บ → บอทเข้าห้อง Meet ได้ (จดเวลาที่ใช้ตั้งแต่กดจนเข้าห้อง: ____ วินาที)
- [ ] บอทเปิด CC ภาษาไทยเอง (ดูที่หน้าจอ Meet ว่ามีแถบคำบรรยายขึ้น)
- [ ] ทุกคนเข้าห้องและพูดทดสอบ 1 ประโยค → เห็นข้อความขึ้นในแท็บ ② ภายในกี่วินาที: ____
- [ ] **ตรวจ:** ชื่อผู้พูดในแท็บ ② ตรงกับชื่อใน Meet หรือไม่ (ถ้าไม่ตรง จดว่าต่างอย่างไร)

## 3) ระหว่างพูดตามบท (5–7 นาที)
ให้ทุกคนพูดตามบท **ธรรมชาติ เว้นจังหวะตอนเปลี่ยนคน ห้ามพูดทับกัน**
- [ ] ข้อความขึ้นต่อเนื่อง ไม่ค้าง/ไม่หลุด
- [ ] ประโยคไม่ซ้ำซ้อนเป็นแถวๆ (CC ของ Meet มักแก้ประโยคเดิมทีหลัง — ดูว่าระบบเก็บซ้ำไหม)
- [ ] ศัพท์อังกฤษ (deploy, API, database, cloud, Gemini) ถอดออกมาเป็นอะไร: ____
- [ ] ตัวเลขและวันที่ (3,000 บาท, 12/14/16 ตุลาคม, บ่ายโมง) ถอดถูกไหม: ____
- [ ] ลองจงใจเปลี่ยนแท็บ/รีเฟรชหน้าเว็บ 1 ครั้งระหว่างประชุม → บอทต้องไม่หลุดและ transcript ไม่หาย
- [ ] ปิดประชุมตามบท → กดหยุดบอท → บอทออกจากห้องเรียบร้อย ไม่มี Chrome ค้างใน Task Manager

## 4) หลังประชุม
- [ ] แท็บ ③ เห็น transcript จัดเป็น "เทิร์นผู้พูด" อ่านได้
- [ ] ตรวจ/แก้ transcript ให้ตรงกับที่พูดจริง (**นับจำนวนที่ CC ถอดผิดไว้**: ____ จุด) แล้วรวมชื่อผู้พูดให้ตรงรายชื่อ
- [ ] กดให้ AI ร่างรายงาน → ได้ผลภายในกี่วินาที: ____ และไม่ error
- [ ] เทียบกับเฉลยใน `SCRIPT_MEETING.md` ด้วยตา (ตัวเลข metric จริงให้รัน eval ในขั้นถัดไป):
  - [ ] วาระ 1 และ 4 **ไม่มีมติ**
  - [ ] วาระ 2 มติ: อนุมัติ 3,000 บาท/เดือน, วาระ 3: ซ้อม 16 ต.ค. 13:00
  - [ ] งาน 5 ตัว ผู้รับผิดชอบและวันกำหนดถูก, งาน "อัปเดตเอกสาร" **ไม่มีวันที่**
  - [ ] หัวรายงาน: ประธาน/เลขา/ผู้มา/ผู้ไม่มา(แพร) ถูก
- [ ] สร้าง PDF → ฟอนต์ไทยแสดงถูก ไม่มีสระลอย/สี่เหลี่ยม ตารางไม่ล้นหน้า
- [ ] ปฏิทิน (ถ้าใช้): นัดซ้อม 16 ต.ค. ถูกสร้างหรือไม่ และเวลาถูกต้อง

## 5) เก็บหลักฐาน
- [ ] ภาพหน้าจอ: Meet ที่มีบอท, แท็บ ②, แท็บ ③, รายงานสุดท้าย
- [ ] export transcript ที่แก้แล้ว → `evaluation/cases/script_meeting_th/transcript.txt` และตั้ง `"synthetic": false` ใน `case.json`
- [ ] เก็บไฟล์ PDF และบันทึกปัญหาที่พบไว้ที่ท้ายไฟล์นี้ (หรือแจ้งผม ผมจะแก้)
- [ ] ขั้นต่อไป: `venv\Scripts\python evaluation\run_eval.py --case script_meeting_th --repeat 3`
