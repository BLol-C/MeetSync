# บทพูดชุดที่ 2: ประชุมต่อจากครั้งแรก ประมาณ 5 นาที

ใช้ทดสอบวาระ 2, 3, 4.1 และการแยก "เรื่องใหม่" ออกจาก "เรื่องเก่า" ต่อจากบทชุดที่ 1 (`SCRIPT_5MIN_1_FIRST.md`)
ผู้พูด 2 คน (บอส = ประธาน, ภาม = เลขา) สลับกันอ่านทีละบรรทัดทุก ~30 วินาที รวม 10 บรรทัด ประมาณ 5 นาที

## ก่อนเริ่ม

1. ประชุมครั้งแรก (บทชุดที่ 1) ต้อง **อนุมัติรายงานแล้ว**
2. สร้างการประชุมใหม่ ตั้ง "ครั้งที่" เป็น 2 และเลือก **การประชุมครั้งก่อน = ประชุมครั้งแรกที่เพิ่งอนุมัติ**
3. รายชื่อ: บอส = ประธาน, ภาม = เลขา ชื่อภาษาอังกฤษตรงกับชื่อใน Meet
4. ถ้าอัดวันอื่น แก้วันที่ในบรรทัดที่ 2 ส่วนวันกำหนดงานเป็นวันตายตัว ไม่ต้องแก้

## บทพูด

| # | เวลา | ผู้พูด | ประโยค |
|---|---|---|---|
| 1 | 00:00 | บอส | สวัสดีครับภาม วันนี้เราประชุมทีมโครงการ MeetSync ครั้งที่สอง มีสามเรื่อง ใช้เวลาไม่นานครับ ภามช่วยจดบันทึกด้วยนะครับ |
| 2 | 00:30 | ภาม | ได้ครับ วันนี้วันที่สิบสองพฤศจิกายน สองพันห้าร้อยหกสิบเก้า มีผู้เข้าประชุมสองคนครับ คือคุณบอสเป็นประธาน และผมเป็นเลขาครับ |
| 3 | 01:00 | บอส | เรื่องแรก รับรองรายงานการประชุมครั้งที่หนึ่ง ผมอ่านแล้ว ขอรับรองโดยไม่มีการแก้ไขครับ |
| 4 | 01:30 | ภาม | ที่ประชุมรับรองรายงานการประชุมครั้งที่หนึ่ง โดยไม่มีการแก้ไขครับ |
| 5 | 02:00 | บอส | เรื่องที่สอง ติดตามงานครั้งก่อน คู่มือผู้ใช้ ผมเขียนเสร็จแล้วครับ ส่วนตารางเฝ้าดูค่าใช้จ่ายรายสัปดาห์ของภามเป็นอย่างไรบ้าง |
| 6 | 02:30 | ภาม | ตารางยังไม่เสร็จครับ ผมขอเวลาถึงวันที่สิบสี่พฤศจิกายน ตามกำหนดเดิม |
| 7 | 03:00 | บอส | ได้ครับ ต่อไปเรื่องที่ค้างจากครั้งก่อน คือเรื่องย้ายระบบขึ้นคลาวด์ ตอนนี้ผมดูแล้วว่ารันบนเครื่องเดียวยังพอครับ |
| 8 | 03:30 | ภาม | ผมเห็นด้วยครับ สรุปว่าที่ประชุมเห็นชอบให้รันบนเครื่องเดียวต่อไปก่อน แล้วค่อยพิจารณาคลาวด์เมื่อมีผู้ใช้พร้อมกันมากขึ้น |
| 9 | 04:00 | บอส | เรื่องที่สาม เรื่องใหม่ ผมเสนอให้ปรับเพดานงบค่า API เป็นเดือนละห้าพันบาท เพราะการทดสอบเพิ่มขึ้นครับ |
| 10 | 04:30 | ภาม | เห็นด้วยครับ ที่ประชุมเห็นชอบเพดานงบเดือนละห้าพันบาท และผมจะแก้ตารางให้ใช้เพดานใหม่ ภายในวันที่สิบเจ็ดพฤศจิกายนครับ |

## เฉลย: สิ่งที่ควรเห็น (ประเมินจากการอ่านบทและโค้ด ยังไม่ได้ทดสอบกับ Meet จริงทั้งชุด)

| วาระ | ควรเป็น |
|---|---|
| **2** รับรองรายงาน | ระบบเติมประโยคตามฟอร์ม (ครั้งที่ 1 วันศุกร์ที่ 7 พ.ย. 2569 เวลา … ณ …) + AI เติมมติ "รับรองโดยไม่มีการแก้ไข" ✓ พบใน transcript |
| **3** เรื่องสืบเนื่อง | งานครั้งก่อนที่ระบบยกมา: **ตารางเฝ้าดูค่าใช้จ่าย** (AI เติมความคืบหน้า "ยังไม่เสร็จ ขอเวลาถึง 14 พ.ย.") และ **คู่มือผู้ใช้** (AI เติม "เขียนเสร็จแล้ว") ผู้ใช้ตรวจ ลบรายการที่เสร็จแล้วออกเองได้ (ระบบไม่เก็บสถานะ "เสร็จ") |
| **4.1** เรื่องค้างพิจารณา | **คลาวด์** (ครั้งที่ 1 ไม่มีมติ) AI เติมมติ "เห็นชอบให้รันบนเครื่องเดียวต่อไปก่อน" |
| **4.2** เรื่องใหม่ | **ปรับเพดานงบเป็น 5,000 บาท** มติเห็นชอบ ต้องเป็นวาระใหม่ **ไม่ถูกซ่อนในงานเก่า** (กับดัก: ใกล้เคียงกับงานตารางค่าใช้จ่าย) |
| งานใหม่ | ภาม: แก้ตารางให้ใช้เพดานใหม่ 17 พ.ย. 2569 (แยกจากงานเก่า) |
| คำเตือน | ไม่ควรมี "ไม่พบวาระที่ AI สกัดได้" |

## สิ่งที่ควรตรวจตอนทดสอบ
- วาระ 4.1 ขึ้นเรื่องคลาวด์ไหม (ถ้าไม่ขึ้น แปลว่ารายงานครั้งที่ 1 มีมติของเรื่องคลาวด์ ตามหมายเหตุในบทชุดที่ 1)
- เรื่องเพดานงบใหม่เป็นวาระ 4.2 แยกต่างหากไหม หรือถูกเอาไปใส่ในความคืบหน้าของงานตาราง (นี่คือจุดเสี่ยงที่ปรับ prompt ไว้)
- ช่องมติที่ AI เติมมี "หลักฐานจาก transcript" และ ✓ พบหรือ ⚠ ไม่พบ ถ้าไม่พบให้ตรวจกับ transcript แล้วแก้
- ช่องมติของรายการที่ไม่ได้พูดถึงต้องว่าง ไม่ถูกเติม
