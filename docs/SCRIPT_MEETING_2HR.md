# บทพูดประชุมจำลอง 2 คน (ประมาณ 2 ชั่วโมง) + เฉลย

ใช้อัดคลิปรันต่อเนื่องของบอท ผู้พูด 2 คนสลับกันอ่านทีละบรรทัดทุก ~43 วินาที รวม 168 บรรทัด ประมาณ 2 ชั่วโมง 0 นาที
ถ้าอ่านจบก่อนเวลาให้รอ ถ้าช้ากว่าให้อ่านต่อ ไม่ต้องรีบตามเวลา มี "กับดัก" ไว้ทดสอบ AI: วาระที่ไม่มีมติ (ห้ามแต่งมติเอง), ข้อเสนอที่ไม่ใช่มติ, งานที่ไม่มีกำหนดวัน,
งานที่เป็นช่วงหลายวัน, งานที่มีช่วงเวลา, วันที่แบบตายตัว, ศัพท์อังกฤษปน (API, transcript, token, Meet)

## ก่อนเริ่ม

| ตัวละคร | บทบาทในระบบ |
|---|---|
| **บอส** | ประธาน (chair) |
| **ภาม** | เลขา (secretary) |

1. สร้างการประชุมที่แท็บ ① ใส่รายชื่อ 2 คน ตั้งบทบาท และชื่อภาษาอังกฤษต้อง **ตรงกับชื่อที่แสดงใน Meet** ของแต่ละคน
2. **วันที่ในบท:** ตั้งวันที่ประชุมเป็น 7 พฤศจิกายน 2569 ถ้าอัดวันอื่นให้เปลี่ยนวันที่ที่พูดในบรรทัดที่ 2 ส่วนวันกำหนดงานเป็นวันตายตัวทั้งหมด ไม่ต้องแก้
3. ถ้าต้องการให้ AI เติมวาระสืบเนื่อง (วาระ 2, 3, 4.1) ต้องมีการประชุมครั้งก่อนที่อนุมัติแล้ว และเลือกเป็น "การประชุมครั้งก่อน" ตอนสร้าง ไม่เช่นนั้นวาระเหล่านี้จะว่าง
4. อ่านออกเสียงชัดๆ ไม่เร็ว **เว้นให้อีกคนพูดจบก่อนเริ่ม อย่าพูดทับกัน** ห้ามปิด/ย่อหน้าต่าง Chrome ของบอท ปิดโปรแกรมที่กินแรม ตั้งเครื่องไม่ให้พักหน้าจอหรือหลับ
5. โควตา Gemini ฟรี 20 ครั้งต่อวันต่อโมเดล ไม่ควรกดสร้างรายงานซ้ำหลายรอบ ถ้าขึ้น 503 ให้รอสักครู่แล้วกดใหม่
