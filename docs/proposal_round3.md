### B1. ชื่อโมเดล (หน้า 32, 38, 41, 42)

**พบ:** หน้า 32 (ตัวอย่าง `model_used`), หน้า 38 (Data Dictionary ช่อง `model_used` ระบุค่าเดียวคือ `'gemini-3.6-flash'`) และหน้า 41 (การทดลองข้อ 2) เขียน `gemini-3.6-flash` แต่หน้า 42 (การทดลองข้อ 7) เขียน `gemini-3.5-flash`

**ข้อเท็จจริงจากระบบ:** ค่าเริ่มต้นในโค้ดคือ `gemini-3.6-flash` (`reports/summarizer.py:33`) แต่ `.env` ในเครื่องนี้ตั้ง `GEMINI_MODEL=gemini-3.5-flash` ดังนั้นรายงานที่สร้างตอนนี้จะบันทึก `model_used = gemini-3.5-flash` และผลวัดชุดข้อ 7 ใช้ตัวนี้

**ต้องตัดสินใจ 1 ข้อ:** ให้ทุกที่ตรงกัน โดยเลือกอย่างใดอย่างหนึ่ง
- (ก) เขียน Proposal ให้เป็น `gemini-3.5-flash` ตามที่ใช้จริง (ง่ายที่สุด และตรงกับผลวัดที่มี)
- (ข) เปลี่ยน `.env` เป็น `gemini-3.6-flash` แล้วรันชุดวัดใหม่ก่อนอ้างผลข้อ 7

**หน้า 38 ช่อง `model_used` แก้เป็น:** Permissible Value = `ชื่อโมเดลตามตัวแปร GEMINI_MODEL (เช่น gemini-3.5-flash)` (ไม่ใช่ค่าตายตัวค่าเดียว)

**ข้อ 2 หน้า 41 (ทดลองคำนวณวันที่):** ถ้าครั้งนั้นรันด้วย `gemini-3.6-flash` จริงก็เขียนตามเดิมได้ แต่ผมยืนยันไม่ได้ ถ้าไม่แน่ใจให้เขียนว่า "ทดลองบนต้นแบบก่อนปรับปรุง" โดยไม่ระบุรุ่น
