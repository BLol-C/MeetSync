## 4. ข้อเท็จจริงของระบบ ณ 16 ต.ค. (ใช้เขียน/ใส่หลักฐาน)
- **ขั้นตอน (5 แท็บ):** ① ข้อมูล+รายชื่อ → ② บอท (สถานะ: กำลังเข้าห้อง / รอเข้าห้อง / ฟังอยู่ / เปิดคำบรรยายไม่ได้ + ตัวนับ "อยู่ในห้องมาแล้ว" + แจ้งเตือนชื่อนอกรายชื่อ) → ③ Transcript + ยืนยันผู้เข้าร่วม → ④ รายงาน (AI ร่าง คนแก้) → ⑤ ตรวจงาน + อนุมัติ + Calendar + PDF
- **ฐานข้อมูล (จาก `db.py`):**
  - `meetings`: meeting_id, owner_user_id, meet_url, title, venue, meeting_no, org_name, scheduled_at, started_at, ended_at, status, previous_meeting_id
  - `speakers`: speaker_id, meeting_id, display_name, meet_alias, email, role, attendance, absence_reason, position, source (registered / meet / excluded), seen_in_room
  - `agenda_items`: agenda_item_id, summary_id, order_no, section, title, discussion, resolution, evidence
  - `action_items`: action_item_id, summary_id, description, assignee, due_date, due_time, due_time_end, evidence, google_calendar_event_id, google_calendar_link
  - `users`, `transcript_segments`, `summaries` ตามที่ Proposal เขียนไว้
- **การจับชื่อ:** ใช้ "ชื่อภาษาอังกฤษ" เทียบตรงตัว (ไม่สนตัวพิมพ์/ช่องว่าง/"(You)") เท่านั้น ไม่เดา
- **สิทธิ์:** ตรวจที่ฝั่งเซิร์ฟเวอร์; ประธาน/เลขาเข้าด้วยอีเมลที่ตรงกับที่ลงทะเบียน; นัด Calendar อยู่ในปฏิทินของผู้กดอนุมัติ ผู้อื่นลบแทนไม่ได้
- **กลไกไม่เชื่อ AI 100%:** ตรวจข้อความอ้างอิงต้องมีใน transcript, ผู้รับผิดชอบต้องอยู่ในรายชื่อ, วันที่สมเหตุผล, คำเตือนตัวเลขกำกวม, คนตรวจ transcript ก่อน AI, คนตรวจ/แก้/อนุมัติรายงาน, ลายน้ำ "ฉบับร่าง", เก็บฉบับ AI เดิมแยกไว้, เก็บโมเดลและเวอร์ชัน prompt ในรายงาน
- **หลักฐานทดสอบที่มี (ใส่ได้ ต้องกำกับข้อจำกัด):**
  - อยู่ในห้อง Meet จริง **66 นาที** (12 ต.ค., แทบไม่มีเสียงพูด): Python ~273–280 MB นิ่ง; ไฟล์ดิบ `docs/evidence/soak_20261012_66min.csv`
  - **63 นาที** (13 ต.ค., 5 คนในห้อง คุยเรื่อยๆ ~430 ช่วง): Python ฐาน ~190–220 MB นิ่ง; Chrome ~700–800 MB เพิ่มราว 6–14% ในช่วงหลัง; ตัวเลข Python บางช่วงสูงเพราะรันเทสต์บนเครื่องเดียวกัน; ไฟล์ดิบ `soak_20261013-192002.csv` อยู่ที่โฟลเดอร์โปรเจกต์ (ไม่ได้ commit)
  - ตัวเลขช่วงต้นสูงเพราะเปิดหน้า Meet จึงไม่ควรอ้างเปอร์เซ็นต์ "ลดลง" ของ 1/4 แรก — เขียนเป็น "ไม่พบแนวโน้มรั่ว"
  - อ่านรายชื่อคนในห้องที่ไม่พูด: ยืนยันบนห้องจริง 16 ต.ค. (ประชุม 110) ห้องเดียว 2 คน
