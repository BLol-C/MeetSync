# บทพูดประชุมจำลอง 2 คน (ประมาณ 1 ชั่วโมง) + เฉลย

ใช้สาธิตให้อาจารย์เห็นว่าระบบรันต่อเนื่อง 1 ชั่วโมงได้ ผู้พูด 2 คนสลับกันอ่านทีละบรรทัดตามเวลาในตาราง (ทุก 40 วินาที)
บทนี้มี "กับดัก" ไว้ทดสอบ AI: วาระที่ไม่มีมติ (ห้ามแต่งมติเอง), งานที่ไม่มีกำหนดวัน, วันที่แบบตายตัว, ศัพท์อังกฤษปน (API, transcript, token, Google Cloud Console)

## ก่อนเริ่ม

| ตัวละคร | บทบาทในระบบ |
|---|---|
| **บอส** | ประธาน (chair) |
| **ภาม** | เลขา (secretary) |

1. สร้างการประชุมที่แท็บ ① ใส่รายชื่อ 2 คน (ผู้ชายทั้งคู่) ตั้งบทบาท ต้อง **ตรงกับชื่อที่แสดงใน Meet** ของแต่ละคน (เปลี่ยนชื่อที่ใช้แสดงใน Meet ให้เป็น บอส / ภาม หรือใช้ชื่ออังกฤษที่ตั้งไว้ในระบบ)
2. **วันที่ในบท:** ตั้งวันที่ประชุมเป็น 31 ตุลาคม 2569 ถ้าซ้อมวันอื่นให้เปลี่ยนวันที่ที่พูดในวาระที่ 1 (บรรทัดที่ 2) ส่วนวันกำหนดงานเป็นวันตายตัวทั้งหมด ไม่ต้องแก้
3. อ่านออกเสียงชัดๆ ไม่เร็ว **เว้นให้อีกคนพูดจบก่อนเริ่ม อย่าพูดทับกัน** (CC ของ Meet จับเสียงทับกันไม่ดี) ถ้าพูดจบก่อนเวลาให้รอ ถ้าช้ากว่าให้อ่านต่อ ไม่ต้องรีบตามเวลา
4. ระหว่างทดสอบ ห้ามปิด/ย่อหน้าต่าง Chrome ของบอท และปิดโปรแกรมอื่นที่กินแรมให้หมด

## เฉลย (สิ่งที่รายงานควรได้)

**ผู้เข้าร่วม:** บอส (ประธาน), ภาม (เลขา) ไม่มีผู้ไม่มาประชุม

**รับรองรายงานครั้งก่อน:** รับรองรายงานการประชุมครั้งที่ 3 โดยไม่แก้ไข

**วาระ 1 แจ้งเพื่อทราบ:** บอทจับคำบรรยายเสถียร, แถบซ้ายแสดงสถานะ Calendar, ผู้ใช้ทดลองเชื่อมปฏิทินไม่ได้ — **ไม่มีมติ**

**เรื่องสืบเนื่อง:** เอกสารขอเบิกงบค่า API ส่งฝ่ายการเงินแล้ว (28 ต.ค.) รออนุมัติ — ปิดงาน ไม่ต้องติดตาม

**มติที่ควรมี (3 ข้อ)**
1. อนุมัติงบค่า API เดือนละ 3,500 บาท และให้แจ้งประธานก่อนถ้าเกินเพดาน (วาระ 2)

3. อยู่ในโหมดทดสอบของ Google ต่อไป และเพิ่มรายชื่อผู้ทดสอบแทนการส่งแอปให้ Google ตรวจ (วาระ 4)
