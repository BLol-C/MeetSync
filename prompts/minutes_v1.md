## กฎสำคัญ
1. ใช้เฉพาะข้อมูลที่ปรากฏใน{source_label}เท่านั้น ห้ามแต่งเติม ห้ามเดา ห้ามสรุปเกินกว่าที่พูดจริง ถ้าไม่แน่ใจให้เว้นว่าง (null)
2. แบ่งเป็น "วาระ" ตามหัวข้อที่ถูกพูดถึงจริง เรียงตามลำดับเวลา แต่ละวาระมี
   - title: ชื่อวาระสั้นๆ
   - discussion: สรุปการอภิปราย ภาษาทางการ บุรุษที่สาม ระบุว่าผู้ใดเสนอ/ชี้แจงอะไร โดยใช้ชื่อตามรายชื่อผู้เข้าร่วม
   - resolution: มติหรือข้อตกลงของที่ประชุมในวาระนั้น **ใส่เฉพาะเมื่อมีการตัดสินใจ/ตกลงกันจริง** ถ้าเป็นเพียงการแจ้งเพื่อทราบหรือยังไม่ได้ข้อสรุปให้เป็น null
   - evidence: ข้อความอ้างอิง 1-2 ประโยคสั้น ที่ **คัดลอกตรงตัวจาก{source_label}** ซึ่งสนับสนุนมติหรือประเด็นหลักของวาระ (ห้ามเรียบเรียงใหม่) ถ้าไม่มีให้เป็นรายการว่าง
3. other_matters: เรื่องอื่นๆ ที่ถูกพูดถึงนอกวาระ ถ้าไม่มีให้เป็น null
4. summary: สรุปภาพรวมการประชุม 3-6 ประโยค
5. action_items: ทุกงานที่ต้องทำและทุกนัดหมาย/กำหนดการ/เดดไลน์ที่ที่ประชุมพูดถึง
   - description: ระบุให้ชัดว่าต้องทำอะไร
   - assignee: ชื่อผู้รับผิดชอบ **ต้องสะกดตรงกับรายชื่อผู้เข้าร่วมด้านบน** ถ้าไม่ชัดเจนหรือไม่อยู่ในรายชื่อให้เป็น null
   - due_date: รูปแบบ YYYY-MM-DD ถ้าบทสนทนาระบุวัน (รวมคำสัมพัทธ์) ต้องแปลงให้เสมอ ถ้าไม่มีให้เป็น null
   - due_time / due_time_end: รูปแบบ HH:MM แบบ 24 ชั่วโมง (เวลาเริ่ม/เวลาสิ้นสุด) ถ้าไม่มีให้เป็น null
   - evidence: ข้อความอ้างอิงที่คัดลอกตรงตัวจาก{source_label} 1 ประโยคสั้น
6. ถ้าไม่มีสาระของการประชุมเลย (เช่น มีแต่การทักทายหรือทดสอบระบบ) ให้ agenda และ action_items เป็นรายการว่าง และบอกใน summary ตามจริง
